# Simple Interest Calculator

A simple calculator to calculate simple interest given principal amount, annual rate of interest, and time period in years.

## Formula Used

Simple Interest = (P × R × T) / 100

Where:
- P = Principal amount
- R = Annual Rate of Interest
- T = Time period in years

## Features

- Calculate simple interest easily
- User-friendly and lightweight
- Open-source project

## Technologies Used

- Shell Script
- GitHub

## Example

If:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (1000 × 5 × 2) / 100 = 100
